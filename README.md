# EclipseID · Цифровая экосистема Империи Плиера

Единый портал государственных услуг для политического ролеплей-сервера в Minecraft.

## Стек

- **Backend:** FastAPI + SQLAlchemy (async)
- **Database:** PostgreSQL
- **Frontend:** Jinja2 + Vanilla JS
- **Auth:** Discord OAuth2 + JWT

## Запуск

```bash
pip install -r requirements.txt
python main.py
